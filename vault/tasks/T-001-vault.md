# T-001 — Creare il vault

**Stato**: done

## Obiettivo

Creare la cartella `vault/` versionata in git come fonte di verità della
pianificazione: indice, roadmap con backlog, e un file per ogni task.

## Checklist

- [x] `vault/README.md` con tabella stato dei task e ordine di esecuzione
- [x] `vault/roadmap.md` con fasi e backlog dei giochi futuri
- [x] Un file `vault/tasks/T-00X-*.md` per ciascun task (T-001..T-008)

## Note

Gli stati vanno aggiornati nello stesso commit in cui il lavoro viene completato.
